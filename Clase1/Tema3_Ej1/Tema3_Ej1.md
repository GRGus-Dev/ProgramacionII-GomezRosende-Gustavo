# Tema 3 Ejercicio 1

## Consigna

Instalar el JDK y un IDE (IntelliJ IDEA), crear un proyecto nuevo y una clase HolaProgramacionII con un método main que imprima un saludo. Verificar desde la terminal las versiones instaladas con java -version y javac -version, y dejar la salida de ambos comandos documentada como comentario al inicio de la clase.

---

## Resolución del problema

Siguiendo con lo específicado por la consigna se realiza un archivo de HolaProgramaciónII con formato java.
Luego se escribirá el código correspondiente abriendo con una clase con el nombre del archivo, luego el metodo main y luego el saludo a imprimirse. Agregando posteriormente el
comentario al comienzo de la versión actual que estoy utilizando de Java que se consiguió haciendo los comandos correspondientes en la terminal.
